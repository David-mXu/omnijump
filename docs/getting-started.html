Getting Started

Follow these three steps to create your first OmniJump shortcut and start using it.

Step 1: Open the Panel

Click the OmniJump extension icon in your Chrome toolbar. The side panel will open on the right side of your browser.

Tip: You can also set a keyboard shortcut to toggle the panel. See Settings for details.

Step 2: Create Your First Shortcut

In the side panel's "Add Redirect" section:

  1. Enter a keyword — something short and memorable, like gh, docs, or news.
  2. Enter the destination URL — the full URL you want to redirect to, like https://github.com.
  3. Press Enter or click the Save button.

The shortcut is instantly saved and syncs to all your signed-in Chrome devices.

Step 3: Use It in the Address Bar

Now whenever you want to visit that URL:

  1. Click the address bar.
  2. Type your keyword (e.g., gh).
  3. Press Enter.

OmniJump redirects you to the saved URL instantly.

What's Next?

  • Create a search shortcut: Use %s in your URL to search sites. Learn more in Search Shortcuts.
  • Create a tab bundle: Save multiple URLs under one keyword. See Tab Bundles.
  • Explore settings: Configure how many shortcuts you want, enable smart suggestions, and more. Check out Settings.

Quick Tips

  • Keyboard navigation: Press Enter in the keyword field to move to the URL field, then press Enter again to save.
  • Right-click shortcuts: Right-click any page or link and select "Save Page as Shortcut" or "Save Link as Shortcut" to create one in a single click.
  • Best address bar experience: If shortcuts feel harder to trigger because browser search suggestions are taking focus, consider turning off address bar search suggestions in your browser settings.
  • Normalize keywords: Keywords are automatically lowercased, and special characters are converted to hyphens. So GitHub!!! becomes github.
