Getting Started

Create your first shortcut and start using it in under a minute.

Step 1: Open the Panel

Click the OmniJump icon in your Chrome toolbar to open the side panel.

Tip: Set a keyboard shortcut in Settings to open and close the panel without touching the mouse.

Step 2: Create Your First Shortcut

In the Shortcuts tab:

  1. Enter a short keyword — something easy to type like gh, docs, or mail.
  2. Enter the destination URL — e.g., https://github.com.
  3. Click + Add or press Enter in the URL field.

The shortcut is saved instantly and syncs to all your signed-in Chrome devices.

Step 3: Use It in the Address Bar

  1. Click the address bar (or press Ctrl+L / ⌘L).
  2. Type your keyword (e.g., gh).
  3. Press Enter.

OmniJump redirects you to the saved URL.

What's Next?

  • Search shortcuts: Type a keyword plus a query to search any site. See Search Shortcuts.
  • Tab bundles: Open several URLs at once with a single keyword. See Tab Bundles.
  • Settings: Adjust limits, enable smart suggestions, configure auto-delete, and more. See Settings.

Quick Tips

  • Keyboard navigation in the form: Press Enter in the keyword field to jump to the URL field; press Enter again to save.
  • Right-click to save: Right-click any page or link and select "Save Page as Shortcut" or "Save Link as Shortcut" — no need to open the panel.
  • Keywords auto-normalize: GitHub!!! becomes github — lowercase, no special characters.
