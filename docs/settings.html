Settings

Open the Settings tab in the OmniJump side panel to configure how the extension behaves.

Dark Mode

Toggle dark mode for the OmniJump interface. Applies to the popup, side panel, and options page.

Smart Suggestions

When enabled, OmniJump tracks which sites you search most. After 5 visits to the same site, a banner appears in the side panel suggesting you create a shortcut for it.

  • The banner pre-fills the keyword and URL for you — click Save to accept.
  • Click Dismiss to hide the suggestion for that site permanently.
  • Toggle off anytime to stop collecting suggestions.

Keyboard Shortcut

Assign a keyboard shortcut to open and close the OmniJump side panel without clicking the toolbar icon.

  • The current shortcut is shown (e.g., Ctrl+Shift+J). If none is set, it will say "not set".
  • Click Customize to go to chrome://extensions/shortcuts where you can assign any key combination.

Max Shortcuts

Set the maximum number of shortcuts you can create (1–500). Default is 500. Once the limit is reached you must delete shortcuts before adding new ones. Lowering this number is useful for keeping your list manageable.

Filter Bar Threshold

The filter bar (search by keyword or URL) appears once your shortcut count reaches this number. Default is 25. Lower it to show the filter bar sooner; raise it to keep the panel simpler when you have fewer shortcuts.

Auto-Delete Stale Shortcuts

Automatically delete shortcuts that haven't been used within a set number of days.

Enable/Disable

Toggle auto-delete on or off. Off by default.

Days Until Deletion

Choose how long a shortcut can go unused before deletion. Range: 7–365 days.

  • 7 days: Aggressive — useful for quickly pruning test shortcuts.
  • 90 days: Default — a reasonable balance for most users.
  • 365 days: Conservative — only removes shortcuts unused for a full year.

Grace Period for New Shortcuts

New shortcuts that have never been used are not immediately eligible for deletion. OmniJump sets their "last used" timestamp to their creation time, giving them a full grace period before they can be auto-deleted.

Usage Chart

A bar chart shows how many shortcuts you opened over the past 7 days — one bar per day. Useful for seeing how actively you're using OmniJump.

Export Shortcuts

Download all your shortcuts as a JSON backup file.

  1. Click Export Shortcuts.
  2. A file named omnijump.json is saved to your computer.

Export File Format

The file is a JSON object with a shortcuts array and a settings object. Each shortcut entry contains:

  • key — normalized keyword
  • type — "redirect", "parameterized" (search shortcut), or "bundle"
  • url — destination URL (redirect and search shortcuts)
  • urlTemplate — search URL with %s placeholder (search shortcuts only)
  • bundleUrls — ordered array of URLs (bundles only)
  • label — optional display label
  • createdAt — Unix timestamp (ms) when the shortcut was created
  • lastUsed — Unix timestamp (ms) of the last activation, or absent if never used

Import Shortcuts

Restore shortcuts from an exported omnijump.json file.

  1. Click Import Shortcuts.
  2. Select a previously exported JSON file.
  3. OmniJump imports all shortcuts from the file.

What Happens on Import

  • Shortcuts in the file are written into your list. Any shortcut with the same keyword as one you already have will overwrite the existing one.
  • Shortcuts you have that aren't in the file are left untouched.
  • All metadata (creation date, last used, labels) is preserved from the file.
  • Settings in the file are applied before shortcuts, so any maxShortcuts value in the file takes effect during the import.

Sync Across Devices

All shortcuts and settings sync automatically to other Chrome devices where you're signed in. Changes propagate within a few seconds with no manual action needed. See the Privacy Policy for how your data is stored.
