Settings

Open the Settings tab in the OmniJump side panel to configure how the extension behaves.

Dark Mode

Toggle dark mode for the OmniJump interface. This affects the popup, side panel, and options page.

  • Off: Light theme (default)
  • On: Dark theme

Smart Suggestions

When enabled, OmniJump watches your search activity. After visiting a search engine or site 5 times, it suggests creating a shortcut for it.

  • A dismissable banner appears: "You often search {Site}. Save '{keyword}' as a shortcut?"
  • The suggestion pre-fills the shortcut form for you.
  • Toggle on/off anytime — dismissed suggestions are forgotten after the session.

Keyboard Shortcut

Configure a keyboard shortcut to instantly open the OmniJump side panel.

  • The current shortcut is displayed (e.g., Ctrl+Shift+J).
  • Click "Customize" to change it.
  • You'll be taken to chrome://extensions/shortcuts where you can assign any key combination.

Max Shortcuts

Set the maximum number of shortcuts you can create. Choose between 1 and 500.

  • Default: 500
  • Once you reach the limit, you'll need to delete shortcuts before creating new ones.
  • Useful for keeping your shortcuts list lean and organized.

Filter Bar Threshold

The filter bar (search by keyword or URL) appears once your shortcut count exceeds this threshold.

  • Default: 25 shortcuts
  • If you have 24 shortcuts, the filter bar is hidden. Once you add the 25th, it appears.
  • Lower this number to show the filter bar earlier; raise it to keep the interface simpler with fewer shortcuts.

Auto-Delete Stale Shortcuts

Automatically remove shortcuts you haven't used in a long time.

Enable/Disable

Toggle auto-delete on or off.

Days Until Deletion

Choose how many days a shortcut can go unused before it's automatically deleted. Options range from 7 to 365 days.

  • 7 days: Aggressive — good if you create many test shortcuts.
  • 30 days: Moderate — default for most users.
  • 90 days: Conservative — keep shortcuts longer.
  • 365 days: Very conservative — only delete after a year of no use.

Grace Period for New Shortcuts

Brand new shortcuts (no usage yet) get a grace period. They won't be deleted immediately even if auto-delete is on. Instead, their first "use" timestamp is set when created, giving them a full grace period to be used before they're eligible for deletion.

Usage Chart

A simple bar chart shows how many times you've used shortcuts over the past 7 days.

  • Each bar represents one day.
  • The chart updates automatically as you use shortcuts.
  • Useful for tracking how actively you're using OmniJump.

Export Shortcuts

Download all your shortcuts as a JSON file for backup or migration.

  1. Click the "Export as JSON" button.
  2. A file named omnibar-shortcuts.json is downloaded to your computer.
  3. Keep this file safe as a backup.

Export File Format

The JSON file contains an array of shortcuts with metadata:

  • key — normalized keyword
  • urls — array of URLs (for bundles; single-item array for redirects)
  • label — optional label (bundles only)
  • createdAt — timestamp when created
  • lastUsed — timestamp of last use (or null if never used)

Import Shortcuts

Restore shortcuts from a previously exported JSON file.

  1. Click the "Import from JSON" button.
  2. Select a previously exported omnibar-shortcuts.json file.
  3. OmniJump imports all shortcuts from the file.

What Happens on Import

  • Shortcuts are merged with your existing ones (not replaced).
  • If a shortcut with the same keyword already exists, it's skipped to avoid conflicts.
  • All metadata (creation date, last used, labels) is preserved.

Sync Across Devices

All settings and shortcuts automatically sync to other Chrome devices where you're signed in.

  • Changes appear on other devices within a few seconds.
  • No manual action required — just sign in to Chrome.
  • See the Privacy Policy for how your data is stored.

FAQ

Settings not saving?

Make sure you're logged into Chrome and syncing is enabled. Check chrome://settings/sync to verify.

Changes on other devices not appearing?

Sync can take a few seconds. Refresh the side panel or wait a moment for changes to appear.

Want to reset to defaults?

Currently, OmniJump doesn't have a "reset all settings" button, but you can delete the extension and reinstall it to start fresh.
