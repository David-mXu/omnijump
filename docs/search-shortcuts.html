Search Shortcuts

Search shortcuts let you type a keyword plus a query in the address bar and redirect directly to a site search URL.

How Search Shortcuts Work

Use %s in your shortcut URL as a query placeholder.

  • Keyword: gh
  • URL: https://github.com/search?q=%s
  • Type in address bar: gh omnijump
  • Result: Opens GitHub search results for "omnijump"

Create a Search Shortcut

  1. Open the OmniJump side panel.
  2. In Add Redirect, enter a short keyword.
  3. Paste a site search URL that includes %s.
  4. Press Enter or click Save.

Use a Search Shortcut

  1. Click the address bar.
  2. Type your keyword, then a space, then your query.
  3. Press Enter.

Example: yt lo fi mixes opens YouTube results for "lo fi mixes".

Ready-to-Use Search Templates

Site Keyword URL Template
Google g https://www.google.com/search?q=%s
GitHub gh https://github.com/search?q=%s
YouTube yt https://www.youtube.com/results?search_query=%s
MDN mdn https://developer.mozilla.org/en-US/search?q=%s
npm npm https://www.npmjs.com/search?q=%s

Behavior Notes

  • Search shortcuts run from the address bar by matching your typed keyword in the search URL.
  • The keyword by itself still works. Example: typing only gh opens the base URL from the shortcut.
  • Use clear, short keywords to avoid conflicts with your normal browsing habits.

Troubleshooting

The shortcut is not triggering

  • Make sure the saved URL includes %s exactly once.
  • Type keyword query with a space between them.
  • Check that no other shortcut uses the same keyword.

Address bar suggestions interfere while typing

If browser search suggestions are crowding the address bar as you type, turning search suggestions off in browser settings can make shortcut triggering feel more predictable.

Need to change a template later

Edit the shortcut from the shortcuts list in the side panel and save again. Changes apply immediately.
