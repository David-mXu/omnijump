Redirect Shortcuts

A redirect shortcut is the simplest way to save a keyword that points to a single URL. Type the keyword in the address bar to jump there instantly.

Creating a Redirect Shortcut

Open the OmniJump side panel and use the "Add Redirect" form:

  1. Enter a short keyword (e.g., docs, mail, spotify).
  2. Paste or type the full destination URL.
  3. Press Enter or click Save.

Using Redirect Shortcuts

Once saved, click the address bar and type your keyword:

  • Type: gh → redirects to your saved GitHub URL
  • Type: docs → redirects to your project docs
  • Type: mail → redirects to your email inbox

Quick-Save from Any Page

OmniJump's popup lets you save the current page as a shortcut instantly:

  1. Click the extension icon while visiting a page.
  2. A popup opens with the page's URL pre-filled.
  3. Enter a keyword and press Enter.

The popup also suggests a keyword based on the page's domain name.

Search Shortcuts (Using %s)

Add %s to your URL to create a search shortcut. When you type the keyword followed by text, it searches the site for that text.

Example: GitHub Search

Create a shortcut with:

  • Keyword: gh
  • URL: https://github.com/search?q=%s

Now type gh my-project in the address bar to search GitHub for "my-project".

Right-Click Shortcuts

Save any page or link without opening the side panel:

  • Right-click a page: Select "Save Page as Shortcut" to save the current URL.
  • Right-click a link: Select "Save Link as Shortcut" to save the link's URL.

A form will pop up where you can confirm or change the keyword before saving.

Editing and Deleting

In the side panel's shortcut list:

  • Click a shortcut row: Edit the keyword and URL inline.
  • Press Escape: Cancel the edit.
  • Click the trash icon: Delete the shortcut.

Keyword Normalization

OmniJump automatically normalizes your keywords for consistency:

  • Converted to lowercase: GitHub becomes github
  • Spaces become hyphens: my docs becomes my-docs
  • Special characters are removed: docs!@# becomes docs
  • Leading/trailing whitespace is trimmed

URL Auto-Completion

If you enter a URL without a protocol (like github.com), OmniJump automatically prepends https://.

Usage Stats

Next to each shortcut in the list, you'll see:

  • Created: When the shortcut was first saved
  • Last used: The last time you activated this shortcut from the address bar

These stats help you identify shortcuts you no longer use, which can be deleted to keep your list clean.
