Redirect Shortcuts

A redirect shortcut saves a keyword that points to a single URL. Type the keyword in the address bar to jump there instantly.

Creating a Redirect Shortcut

Open the OmniJump side panel → Shortcuts tab:

  1. Enter a short keyword (e.g., docs, mail, spotify).
  2. Paste or type the destination URL.
  3. Click + Add or press Enter in the URL field.

The shortcut is saved instantly and synced to your other Chrome devices.

Using Redirect Shortcuts

Click the address bar, type the keyword, and press Enter:

  • gh → jumps to your saved GitHub URL
  • docs → jumps to your project docs
  • mail → jumps to your email inbox

Quick-Save from Any Page

Click the OmniJump extension icon while on any page to open the popup. The current URL is pre-filled and a keyword is suggested from the domain name. Edit if needed and press Enter to save.

Right-Click to Save

Save a page or link without opening the side panel:

  • Right-click a page: Select "Save Page as Shortcut".
  • Right-click a link: Select "Save Link as Shortcut".

OmniJump auto-generates a keyword from the URL and saves it immediately — the shortcut appears in your list right away.

Editing and Deleting

In the side panel's shortcut list:

  • Click the pencil icon to edit the keyword or URL inline.
  • Click Cancel to discard changes.
  • Click the × icon to delete the shortcut.

Keyword Normalization

OmniJump automatically normalizes keywords for consistency:

  • Converted to lowercase: GitHub → github
  • Spaces become hyphens: my docs → my-docs
  • Special characters are removed: docs!@# → docs
  • Leading/trailing whitespace is trimmed

URL Auto-Completion

Enter a URL without a protocol (e.g., github.com) and OmniJump automatically prepends https://.

Usage Stats

Each shortcut in the list shows how many times it's been used and when it was last activated. These stats help you identify shortcuts you no longer need.

Want to Search a Site?

For shortcuts that search a site (e.g., type gh my-project to search GitHub), use a Search Shortcut instead. See Search Shortcuts.
