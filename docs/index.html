OmniJump Documentation

OmniJump lets you save short keywords and use them in the address bar to jump to URLs, search sites, or open groups of tabs instantly.

What Can You Do?

  • Redirect shortcuts: Type a keyword in the address bar to jump to any URL instantly.
  • Search shortcuts: Type a keyword plus a query (e.g., gh omnijump) to search GitHub. Powered by a %s URL template. See Search Shortcuts.
  • Tab bundles: One keyword opens a whole set of URLs — great for daily workflows.
  • Smart suggestions: After visiting a search site a few times, OmniJump suggests creating a shortcut for it.
  • Sync across devices: Shortcuts sync automatically to all signed-in Chrome devices.
  • Export and import: Back up your shortcuts as JSON or restore from a backup.
