OmniJump Documentation

OmniJump lets you save keywords that redirect the address bar to any URL, or open multiple URLs as a bundle with a single keyword.

What Can You Do?

  • Redirect shortcuts: Type a keyword in the address bar to jump to any URL instantly.
  • Search shortcuts: Use %s to search multiple sites. Type gh my query to search GitHub for "my query". See Search Shortcuts.
  • Tab bundles: Save a keyword that opens multiple URLs at once — perfect for daily workflows.
  • Smart suggestions: After visiting a search site a few times, OmniJump suggests a shortcut for it.
  • Sync across devices: Shortcuts sync automatically to all your signed-in Chrome devices.
  • Export and import: Backup your shortcuts as JSON or restore from a backup.
